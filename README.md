# 💧 Calculadora Fácil de Reparto de Agua para Edificios

Esta es una **solución web simple y accesible** diseñada para administradores de edificios o propiedades con varios inquilinos. Su propósito es distribuir la factura mensual de agua de forma **justa y exacta** basándose en las lecturas individuales de cada contador.

El objetivo principal es eliminar los errores humanos y las complicaciones de las matemáticas complejas.

## ✨ Funcionalidades Clave de la Aplicación

La aplicación está diseñada pensando en la facilidad de uso, especialmente para personas de la tercera edad:

1.  **Memoria Automática:** Al presionar "Calcular", la aplicación guarda la última lectura actual de cada piso. Cuando se vuelve a abrir, **ese valor se coloca automáticamente** como la Lectura Anterior para el nuevo mes, ahorrando tiempo y asegurando la continuidad del cálculo.
2.  **Fácil Cobro (Redondeo a $50):** Todos los montos a cobrar se redondean automáticamente al múltiplo de **50 pesos** más cercano, facilitando el pago en efectivo y evitando el uso de monedas pequeñas.
3.  **Estructura Fija y Limpia:** Los 4 pisos (Piso 3, 2 Frente, 2 Atrás, 1) están fijos en el diseño, eliminando la posibilidad de borrar o agregar unidades por error. Solo hay que concentrarse en ingresar los números.
4.  **Cuadre Transparente:** El resumen de resultados indica cuánto dinero se ha recaudado con los cobros redondeados, y si existe un pequeño sobrante o faltante respecto a la factura total, manteniendo las cuentas claras.

## 📝 Pasos para Usar la Calculadora

El proceso se reduce a tres acciones sencillas:

1.  **Monto Total:** Ingrese el valor total de la factura de agua.
2.  **Medidores:** Escriba la **Lectura Actual** de cada contador. La aplicación automáticamente tomará la lectura anterior guardada.
3.  **Resultado:** Presione **CALCULAR COBROS** para obtener el monto exacto que debe pagar cada inquilino.
